# 14일차 오늘 입력할 프롬프트

> 강사가 안내할 때 한 블록씩 입력합니다. 표준화·모델 생성·모델 평가를 한 번에 실행하지 않습니다.

## STEP 1 — 표준화 전후 K-means

### 프롬프트 1: 원본값으로 모델 생성

```text
bike_station_profile.csv에서 일평균이용건수, 출근시간비중, 퇴근시간비중, 주말비중, 거치대당일평균이용건수만 선택해줘.
표준화하지 말고 KMeans를 k=4, random_state=42, n_init=20으로 학습해 군집 열만 추가해줘.
아직 군집을 평가하거나 이름을 붙이지 마.
여기까지만 진행하고 결과를 보여준 뒤 멈춰줘.
```

### 프롬프트 2: 원본값 모델 평가

```text
방금 만든 원본값 군집의 군집별 대여소 수와 다섯 원본 지표 평균을 보여줘.
군집 이름이나 운영전략은 제안하지 마.
여기까지만 진행하고 결과를 보여준 뒤 멈춰줘.
```

### 프롬프트 3: 표준화만 실행

```text
같은 다섯 변수에 StandardScaler만 적용해 표준화된 데이터 5열을 만들어줘.
KMeans는 아직 학습하지 마.
각 열의 평균이 약 0, 표준편차가 약 1인지 보여줘.
여기까지만 진행하고 결과를 보여준 뒤 멈춰줘.
```

### 프롬프트 4: 표준화 데이터로 모델 생성

```text
방금 만든 표준화 데이터로 KMeans를 k=4, random_state=42, n_init=20으로 학습해 새 군집 열만 추가해줘.
아직 군집을 평가하거나 이름을 붙이지 마.
여기까지만 진행하고 결과를 보여준 뒤 멈춰줘.
```

### 프롬프트 5: 표준화 모델 평가

```text
표준화 후 군집의 군집별 대여소 수와 다섯 원본 지표 평균을 보여줘.
표준화 전 결과와 같은 표 구조로 보여주고 이름은 붙이지 마.
여기까지만 진행하고 결과를 보여준 뒤 멈춰줘.
```

전체 2,782곳 평균도 같은 원본 단위로 함께 보여줘.

## STEP 3~4 — 완성 대시보드 조작

이 단계에서는 새 코드를 만들지 않습니다. 강사가 연 `dashboard/index.html`을 함께 조작합니다.

1. 동일 가중치 20%에서 군집 수와 변경 대여소 수를 확인합니다.
2. 출근시간비중 80%, 나머지 5%로 바꿉니다.
3. `가중치 반영해 다시 묶기`를 누릅니다.
4. 군집 카드를 선택합니다.
5. 지도 마커나 목록에서 정거장을 선택해 다섯 원본 지표를 확인합니다.
