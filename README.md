# 📊 대시보드 웹호스팅 실습 (Dashboard Web Hosting Practice)

본 프로젝트는 3040 맞벌이 가구를 위한 서울시 최적 주거지 분석 및 대시보드 웹호스팅 실습을 진행하는 저장소입니다.

---

## 📌 주요 실습 내용

1. **데이터 수집 및 정제**
   - 서울시 아파트 실거래가, 상권 데이터, 인구 이동 데이터 정제 및 통합
2. **클러스터링 및 TOPSIS 모델링**
   - 3040 맞벌이 부부 맞춤형 최적 주거지 추천 알고리즘 적용
3. **대시보드 웹호스팅 (Web Hosting)**
   - Interactive GIS 지도 대시보드 및 통합 분석 리포트 HTML 제작
   - GitHub Pages 및 웹 호스팅 환경을 통한 대시보드 서비스 배포 실습

---

## 📁 주요 파일 및 프로젝트 구조

- `README.md`: 프로젝트 안내 문서
- `프로젝트/`: 대시보드 및 웹호스팅 관련 리소스
  - `3040_맞벌이_주거지_지도_대시보드.html`: GIS 기반 웹 지도 대시보드
  - `seoul_apt_dashboard.html`: 서울시 아파트 분석 웹 대시보드
  - `발표용 공유/최종/index.html`: 웹 배포 메인 리포트 페이지

---

## 🚀 시작하기 & 사용 방법

1. 저장소 클론 (Clone)
   ```bash
   git clone https://github.com/kimsaemi/frist_board.git
   ```
2. 대시보드 실행
   - `프로젝트/3040_맞벌이_주거지_지도_대시보드.html` 또는 `index.html` 파일을 웹 브라우저에서 열어 확인합니다.
